# 🧮 Calculator App

## 📌 Overview

A modern, responsive calculator built using vanilla HTML, CSS, and JavaScript.
This project focuses on clean UI design, efficient event handling, and an improved user experience through keyboard support.

---

## 🚀 Features

* Perform basic arithmetic operations (+, −, ×, ÷)
* Real-time display updates
* Keyboard input support
* Clear and delete functionality
* Error handling for invalid expressions
* Responsive and modern UI

---

## 🛠️ Tech Stack

* **HTML5** – semantic structure
* **CSS3** – Grid layout & modern styling
* **JavaScript (ES6)** – application logic & event handling

---

## 🧠 Key Concepts Used

* Event delegation for handling button clicks efficiently
* DOM manipulation for dynamic updates
* Separation of concerns (HTML, CSS, JS)
* Keyboard event handling for better UX
